# User guide

[Documentation](../README.md) · [Installation](getting-started.md)

## Account and library

Register or sign in, then open My materials. Email identifiers are case-insensitive; passwords must contain 15–128 characters. See [Limitations](limitations.md) for unsupported account features. Saved materials and study records remain available after signing in from another browser.

## Upload and analyze

1. Select one or more files, then check source order, conversion status, and PDF previews.
2. Retry conversion or remove failed files. When all selected sources are ready, choose Start analysis.
3. Open the published map and check partial or review-required content against the source.

Closing a page does not cancel server work. Failed analysis can resume saved progress. To replace a source, return to the source page, remove it, upload the replacement, and start analysis again. Sources referenced only by failed or cancelled work can leave the active list; active or published sources remain protected.

This edition reads native text only. Image-only sources are rejected and excluded pages remain available in the original PDF. Formats, sizes, and locator accuracy are described in [Material processing](materials.md).

## Explore the map

The map shows a two-hop neighborhood of the selected concept. Search and the learning guide reach concepts outside the current canvas; display limits never remove knowledge from the saved structure.

Concept details show key points, source links, and study actions. On mobile, details appear in a dialog. Source links open the matching PDF page or download the original. Browsing the map or sources does not generate questions.

## Practice and follow-up

Enter a concept and explicitly start its practice set. The number of questions follows eligible source points. You may leave while questions are being prepared and return to the same set; different concepts retain independent sets.

Answer all published questions, submit the set, and review grading, explanations, and sources. Unsubmitted selections are not saved. Retrieve the saved result after a lost response; refresh a conflicting version before confirming a resubmission.

For missed points, read the source and start follow-up practice. Each round requires an explicit action. A follow-up pass indicates improvement in that exercise, not independent long-term mastery; see [Learning and assessment](learning.md).

Refreshing or signing in again restores saved sets and results. The result page offers continued practice, the next concept, or completion.

## Update and delete

Rename a material or add sources to create a new map revision. Failed or cancelled updates preserve the published map and study records. Unchanged, uniquely matched points can carry forward answer evidence.

Deleting an entire material removes its sources, maps, questions, and study records after confirmation. Active work is stopped safely before cleanup.
